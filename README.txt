How to open
-----------
1. Extract the ZIP file.
2. Open the prince_portfolio folder in Visual Studio Code.
3. Open index.html in a browser, or use the Live Server extension.
4. Keep the assets folder beside index.html. Do not rename or move it.

Responsive design notes
-----------------------
The stylesheet uses fluid widths, clamp-based typography and additional
breakpoints for narrow phones, landscape phones, tablets, laptops and wide
monitors. The education table scrolls horizontally on narrow screens to keep
its columns readable. Test at common widths such as 320, 375, 430, 768,
1024 and 1440 pixels, plus rotate a phone to landscape.
